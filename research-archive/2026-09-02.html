HiRS-Agent: A Hierarchical Multi-Agent System for Reliable Long-Horizon Remote Sensing Task Solving
HiRS-Agent：用于可靠长时序遥感任务求解的分层多智能体系统

提出了HiRS-Agent，一个用于长时序遥感任务求解的分层多智能体系统。系统采用两层协作架构：管理层负责动态路由、验证、重规划和终止控制；专家层根据遥感工作流组织领域特定工具并负责子任务推理。通过两阶段监督微调和验证引导的分层强化学习进行优化，在Earth-Agent Benchmark和ThinkGeo上显著提升了长时序工具使用能力和任务正确性。

A Composition-Aware Pretraining Framework for Geospatial Foundation Models
地理空间基础模型的组成感知预训练框架

提出了一种组成感知的预训练框架，将每个卫星图像单元映射到其土地覆盖分数直方图作为预测目标，并使用推土机距离进行蒸馏。实验表明，该方法在区域级理解任务（如零样本图像检索和场景分类）上显著优于SatMAE和Prithvi-EO-2.0等更大模型，并在细粒度数据集ForestNet-12上取得了大幅提升。

GeoRisk-RAG: A Hierarchy-Aware Risk Framework for Improving RAG Reliability through Selective Answering
GeoRisk-RAG：一种层级感知的风险框架，通过选择性回答提高RAG可靠性

针对大语言模型在自然灾害管理中难以区分语义相似性与地理有效性的问题，提出GeoRisk-RAG框架。该框架在生成回答前，使用基于有向无环图的距离显式估计地理适用性，并支持选择性回答。在野火问答数据集上，该方法将位置相关问题的错误置信率从约0.090降至0.009，并获得了更高的人类偏好一致性。

SERA-H: Super-Resolution of Sentinel Time Series for Fine-Scale Canopy Height Mapping
SERA-H：用于精细冠层高度制图的Sentinel时间序列超分辨率

提出SERA-H模型，结合超分辨率模块和时序注意力编码，在LiDAR衍生的冠层高度模型监督下，从免费的Sentinel-1和Sentinel-2时间序列数据生成2.5米分辨率的高度图。在法国基准数据集上，MAE为2.6米，R²为0.82，性能接近基于商业高分辨率影像的方法，且仅依赖免费数据。

GridFlow: Structured Latent Flow for Seamless City-Scale 3D Point Cloud Generation
GridFlow：用于无缝城市尺度3D点云生成的结构化潜流

提出了一个多阶段框架GridFlow，用于从卫星影像、语义分割图和数字表面模型（DSM）等遥感数据中生成城市尺度的密集彩色3D点云。该方法采用网格对齐VAE、条件整流流模型和方向感知扩散着色器，实现了跨瓦片无缝生成。作者还构建了包含16.3万个标注瓦片的City3D-MultiGen基准数据集。

SAGE-XGBoost: Spatially Augmented Graph Embeddings--Machine Learning Framework for Natural Hazards Susceptibility Mapping under Data Scarcity
SAGE-XGBoost：用于数据稀缺条件下自然灾害易发性制图的空间增强图嵌入机器学习框架

提出SAGE框架，通过基于噪声的数据增强和邻域图嵌入来改进数据稀缺条件下的预测。使用K近邻图提取局部空间统计量，经PCA降维后与协变量结合，用于XGBoost模型。在滑坡和野火易发性制图中，SAGE-XGBoost比空间XGBoost的AUC绝对提升超过33个百分点，分别达到约0.97和0.95。
